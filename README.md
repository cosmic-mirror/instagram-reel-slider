# Instagram Reel Slider Userscript

## Installation
To install the userscript, you will need a userscript manager such as Tampermonkey or Violentmonkey. Follow these steps:
1. Install a userscript manager from your browser's extension store.
2. Create a new script and paste the code from the [GitHub repository](https://github.com/spactable/instagram-reel-slider).
3. Save the script.

## Usage
Once installed, the userscript will automatically activate when you visit the Instagram website. You can use it to enhance your browsing experience with Instagram Reels.

## Keyboard Shortcuts
- **Arrow Left**: Skip to the previous reel.
- **Arrow Right**: Skip to the next reel.
- **Space**: Play/Pause the current reel.

## Debugging
If you encounter issues:
- Check the browser console (F12) for error messages.
- Ensure the userscript manager is enabled and the script is active.
- Consult the [GitHub Issues page](https://github.com/spactable/instagram-reel-slider/issues) for support and reporting bugs.
